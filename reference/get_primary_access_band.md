# Return the primary access band in the requested units.

Return the primary access band in the requested units.

## Usage

``` r
get_primary_access_band(units = c("min", "sec"))
```

## Arguments

- units:

  \`"min"\` (default) or \`"sec"\`.

## Value

Integer scalar – \[PRIMARY_ACCESS_BAND_MIN\] or
\[PRIMARY_ACCESS_BAND_SEC\].
