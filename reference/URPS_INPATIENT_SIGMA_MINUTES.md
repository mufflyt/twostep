# Calibrated bandwidth in minutes

Measured, not assumed: converted from \[URPS_INPATIENT_SIGMA_MILES\]
using real Massachusetts road-network isochrones for the FPMRS/urology
cohort (30 min = 15.6 mi, 60 = 35.7, 120 = 70.1, 180 = 101.8; log-log R2
= 0.997).

## Usage

``` r
URPS_INPATIENT_SIGMA_MINUTES
```

## Format

Numeric scalar, minutes.
