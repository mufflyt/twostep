# Data Ownership Boundary

Concise companion to [`REPO_CHARTERS.md`](REPO_CHARTERS.md). It fixes which repo
owns which class of truth so the four repos never drift back into overlapping
sources of truth. One direction of dependency only (see the charter diagram).

## mufflyaccess owns

- Workforce **measure definitions** (`board_certified_active`, `roster_snapshot`)
- Provider **pathway reconciliation** (ABOG / ABU net-new / combined)
- **National, CONUS, and state workforce counts**
- Artifact **provenance**
- **Semantic validation** of counts
- The **snapshot vs active-workforce** distinction (e.g. 2025 roster_snapshot 1,339
  is NOT the 2023 board_certified_active count 1,332)

## twostep owns

- **Population denominators** (ACS)
- **Supply-to-population** measures
- **E2SFCA** calculations
- **Geography-specific demand** estimates

## isochrones owns

- **Travel-time bands**
- **Reachability** calculations
- **Spatial access surfaces**
- **Geographic routing** artifacts

(isochrones also builds the provider-level roster that feeds the counts
mufflyaccess publishes; see the charter. The list above is its *access-surface*
ownership, which twostep and cliff must not reconstruct.)

## Enforced boundaries (in code, not just prose)

| Rule | Enforced by |
|---|---|
| No ACS population fields generated by mufflyaccess | mufflyaccess ships counts + provenance only; it does not compute denominators |
| No provider-roster reconstruction in twostep | `tests/testthat/test-no-urps-count-derivation.R` (no derived/hardcoded counts) + `test-urps-consumer-contract.R` (twostep reconciles to `urps_count()`, never redefines) |
| No workforce totals hard-coded in isochrones | isochrones emits the count artifact; the literal lives only in that artifact + the release contract |
| No access claims from workforce counts alone | twostep must pair a workforce numerator with a population/access denominator on the **same geography**: `assert_matching_geography()` (`R/geography_agreement.R`) is a fail-loud precondition of every supply-to-demand ratio |

## The numerator/denominator geography rule

Any twostep supply-to-demand ratio combines a workforce **numerator** (providers,
from the isochrones roster via the mufflyaccess SSOT) with a population/access
**denominator** (twostep's ACS denominators). They must be on one geography:

```r
assert_matching_geography(workforce_geography, denominator_geography)
```

A national numerator over a CONUS denominator (or vice versa) silently biases
every accessibility score; this precondition makes it a hard error.
